# Eurêka

Le quiz qui corrige au stylo vert. On coche, on se trompe, le stylo rouge corrige, le stylo vert explique, et les erreurs reviennent jusqu'à ce qu'on les retienne.

Laravel 13 · Inertia 3 · Vue 3 · Tailwind 4 · Pest

```bash
composer install && npm install
cp .env.example .env && php artisan key:generate
php artisan migrate --seed
composer run dev
```

Compte de démonstration (hors production) : `demo@eureka.test` / `password`.
